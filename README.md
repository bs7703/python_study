 Quiz Program Project (v1.0)
1. 프로젝트 개요
본 프로젝트는 파이썬을 이용한 객체지향 기반의 퀴즈 게임 프로그램입니다. 외부 JSON 파일을 통해 퀴즈 데이터를 관리하며, 사용자의 최고 점수를 유지하고 퀴즈를 직접 추가/삭제할 수 있는 기능을 제공합니다.

2. 퀴즈 주제와 선정 이유
주제: 일반 상식 및 프로그래밍 기초 (천문학, 예술, 과학, 역사, 파이썬 등)
선정 이유:
다양한 분야의 데이터를 다룸으로써 JSON 데이터 구조(List, Dict)의 활용 능력을 높이기 위함입니다.
정답, 배점, 힌트, 해설 등 다각도의 데이터를 처리하는 로직을 구현하기에 적합한 주제입니다.
3. 실행 방법
파이썬이 설치된 환경에서 터미널(CMD)을 실행합니다.
프로젝트 폴더로 이동합니다.
'python quiz_game.py' 명령어를 입력하여 게임을 시작합니다.
(주의: config.json, basic_data.json, constants.py, quiz.py 파일이 동일 경로에 있어야 합니다.)
4. 기능 목록
퀴즈 시작: 로드된 퀴즈를 풀고 점수를 획득합니다. (힌트 사용 시 점수 차감 로직 포함)
점수 확인: 현재까지 기록된 최고 점수(Best Score)를 확인합니다.
퀴즈 관리: 새로운 퀴즈를 추가하거나 기존 퀴즈를 목록에서 삭제할 수 있습니다.
데이터 보존: 퀴즈 추가/삭제 및 최고 점수 업데이트 시 'state.json'에 즉시 또는 종료 시 저장됩니다.
예외 처리: 데이터 파일이 손상되거나 없을 경우 기본 백업 파일에서 데이터를 복구합니다.
5. 파일 구조
quiz_game.py: 메인 게임 로직 및 UI 제어 클래스
quiz.py: 개별 퀴즈 객체를 정의하는 클래스
constants.py: 프로그램에서 사용하는 모든 상수 및 에러 메시지 관리
config.json: 게임 제목, 메뉴 구성, UI 스타일, 게임 계수 설정
state.json: 사용자의 현재 진행 상태 및 업데이트된 퀴즈 데이터 저장
basic_data.json: 초기 데이터 및 오류 발생 시 참조할 백업 데이터
6. 데이터 파일 설명 (state.json)
경로: 프로그램 실행 루트 폴더 내 './state.json'
역할: 사용자의 최고 점수와 최신 퀴즈 리스트를 유지하는 영구 저장소입니다.
스키마(구조):
best_score: (Number) 역대 최고 점수
quizzes: (Array) 퀴즈 객체들의 리스트
question: (String) 문제 내용
choices: (Array) 4개의 선택지 문자열
answer: (Number) 정답 번호 (1~4)
answer_point: (Number) 문제 배점
hint: (String) 힌트 내용
explanation: (String) 문제 해설
